# Results

`original-notebook-observation.json` is a faithful, machine-readable
transcription of the timing that motivated this repository. It preserves the
provenance and caveat associated with the headline number.

Generated benchmark artifacts are written under `artifacts/` and excluded from
version control because full runs and optional checkpoints can be large. A
complete result record consists of the aggregate `benchmark.json`, raw
per-profile `result.json` files, hardware and software metadata, repeat/epoch
counts, and accuracy metrics. Model checkpoints and the Food-101 image archive
are not part of the source repository.
